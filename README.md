# Claude Code LSP snippets

Copy the **entire file** for your agent's language to the destination below,
relative to your solution repository root. Then return to CodeCrafters for setup.

| Language | Client file | Destination |
| --- | --- | --- |
| C | [lsp_client.h](c/lsp_client.h) | `src/lsp_client.h` |
| C++ | [lsp_client.hpp](cpp/lsp_client.hpp) | `src/lsp_client.hpp` |
| C# | [LSPClient.cs](csharp/LSPClient.cs) | `src/LSPClient.cs` |
| Go | [lsp_client.go](go/lsp_client.go) | `app/lsp_client.go` |
| Java | [LSPClient.java](java/LSPClient.java) | `src/main/java/LSPClient.java` |
| JavaScript | [lsp_client.js](javascript/lsp_client.js) | `app/lsp_client.js` |
| Python | [lsp_client.py](python/lsp_client.py) | `app/lsp_client.py` |
| Rust | [lsp_client.rs](rust/lsp_client.rs) | `src/lsp_client.rs` |
| TypeScript | [lsp_client.ts](typescript/lsp_client.ts) | `app/lsp_client.ts` |
| Zig | [lsp_client.zig](zig/lsp_client.zig) | `src/lsp_client.zig` |

These files connect to the course-supplied helper; they do not implement the
model-facing LSP tool. Current starters already include them.
